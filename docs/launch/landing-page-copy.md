## 3. The 5 Core Claims

### 1. Your AI chief of staff is a folder.
You do not need a complicated backend, a database service, or another monthly SaaS fee. By structuring instructions, rules, and memory files into a clean folder hierarchy, your AI terminal assistant transforms into a dedicated executive partner.

### 2. Use the AI you already pay for.
Why pay extra for a middleman wrapper? Folder Chief is designed to work with the frontier AI tools already on your machine—Claude Code, OpenAI Codex CLI, Google Gemini CLI, or OpenCode (independent validation scheduled).

### 3. Your memory is files you own.
Your notes, project profiles, meeting takeaways, and daily commitments are written in standard Markdown files inside `brain/`. You can edit them in VS Code, search them with standard tools, or visualize them in Obsidian.

### 4. Nothing runs unless you invite it.
True consent-based assistance. Folder Chief core is 100% interactive, local, and inert-by-default. There are no background listeners, open network ports, or hidden daemon processes. It only acts when you open a terminal and converse with it. It prepares safe drafts; you hold the execution keys.

### 5. When work deserves an employee, your Chief hires one.
When a recurring responsibility develops standing state and a regular rhythm, your Chief guides you through an interview and scaffolds a specialized **Folder Agent** in `team/<agent-name>/` with its own contract, private working directory, and acceptance scenarios. It executes only when you open a terminal in that folder and launch your AI assistant—never running autonomously in the background.

## 4. Key Features

### 📁 Compiled Markdown Memory
Raw materials dropped into `brain/inbox/` are filed immutably into `brain/sources/`. The Chief compiles clean, source-attributed synthesis into `brain/notes/`. If a note is ever questioned, it links directly to the original document.

### 🕸️ Native Obsidian Vault
The entire `brain/` directory is designed as a first-class Obsidian vault. Enjoy automatic bidirectional linking, tag exploration, interactive graph views, and dynamic task dashboards with Obsidian Bases.

### 🛡️ Explicit Capabilities & Zero Stored Secrets
Folder Chief maintains a strict distinction between what is possible in principle and what is configured on your machine. API keys and passwords never touch the folder; they stay in your operating system keychain or environment variables.

### 🤝 Specialized Folder Agents
Scale your productivity by delegating specific responsibilities to Folder Agents (such as pipeline tracking, competitive monitoring, or content synthesis). Each agent operates within its own bounded directory and reports progress to the Chief.

### 📖 Modular Built-in Manual
The Chief understands itself through a comprehensive manual in `chief/manual/`. It explains its own architecture, governance rules, and setup steps deterministically without confusing general AI trivia with its real capabilities.

### 🔄 Git-Native Upgrades & Backups
Backing up your personal memory is as simple as copying the folder or initializing a private Git vault. Upgrading product templates is a single `git pull`—product manuals update while your private notes, session journals, and agents remain untouched.

## 5. Frequently Asked Questions (FAQ)

#### What AI coding assistants are supported?
Folder Chief is built on open instruction standards and is designed for Claude Code, OpenAI Codex CLI, Google Gemini CLI, and OpenCode (independent multi-harness validation scheduled).

#### Does Folder Chief send my private files anywhere?
Folder Chief itself has no servers, no analytics, and no telemetry. All files reside locally on your machine. However, when you interact with Folder Chief using your AI CLI (e.g. Claude Code, Codex, or Gemini CLI), prompts and context files are transmitted to and processed by that AI provider under their commercial terms of service and privacy policies.

#### How is this different from standard chat memory features?
Standard chat memory is hidden, unstructured, and tied to a single proprietary vendor. Folder Chief stores memory as structured, transparent Markdown files that you can inspect, version with Git, link across notes, and view in Obsidian.

#### Can Folder Chief connect to my email, calendar, or web search?
Folder Chief includes reference architecture guides for connecting web search, shell tools, email drafting, calendar lookups, and notifications. However, fresh installations start with zero tool access until you explicitly configure them. External sends always remain drafts for your review.

#### What happens if I want to delete everything or start over?
Because everything is a plain folder, you are in complete control. To forget your user profile, delete `brain/me.md`. To start fresh, delete the folder.
