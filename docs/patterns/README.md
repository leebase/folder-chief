# Folder Chief Patterns & Playbooks

> **Repeatable workflows, collaboration blueprints, and migration recipes.**

Folder Chief is designed to be minimal and unopinionated: a clean folder structure, a behavioral contract (`AGENTS.md`), and an empty `brain/` vault for your thoughts.

**Patterns** are tested, modular playbooks that demonstrate how to apply Folder Chief to specific workflows, organizational challenges, and multi-tool transitions.

---

## Available Patterns

### Onboarding & Migration
- **[AI Relationship Transfer](ai-relationship-transfer.md)**
  Transfer your established working rapport, communication preferences, and active project context from an existing AI assistant (ChatGPT, Claude Web, Gemini Web) into Folder Chief without starting from zero.

### Collaboration & Operating Models
- **[AI Leadership Team](ai-leadership-team.md)**
  Pair an independent Strategic Advisor (in Claude Web, ChatGPT, or Gemini) for high-level reasoning with your Chief of Staff (Folder Chief) for operational memory, project tracking, and specialist execution.

---


## What Makes a Folder Chief Pattern?

Every pattern in this directory adheres to our core design principles:

1. **Local-First & Portable:** Patterns rely only on plain Markdown files and work across Claude Code, Codex, Gemini CLI, and OpenCode.
2. **Human in Control:** Patterns empower the human owner to inspect, edit, and govern memory rather than relying on black-box background automation.
3. **Inspectable Artifacts:** Every pattern produces clear, human-readable documents in `brain/` or `team/` that outlive the session.
4. **Zero Proprietary Lock-In:** Patterns never require external database infrastructure, third-party subscriptions, or proprietary formats.
