# Why a Folder, Not an App?

> **Why choose a folder of Markdown over another AI app subscription?**

Every week, new AI assistant apps, web dashboards, and productivity tools launch. Most of them ask you to upload your data to their cloud, pay a monthly subscription, and trust their proprietary memory database.

Folder Chief takes the opposite approach: **your assistant is a folder on your computer.**

## The Core Advantages

### 1. True Data Permanence
If a SaaS startup shuts down or changes its pricing, your data and workflows vanish. With Folder Chief, your notes, project histories, and knowledge base are standard Markdown files that will remain readable and useful decades from now.

### 2. Multi-Tool Portability
You are not married to a single AI model provider. If you use Claude Code today, Codex tomorrow, and Gemini CLI next week, your Chief of Staff retains the exact same memory, project state, and operating context across all of them.

### 3. Infinite Inspectability
In typical AI tools, you have no idea what the model has "learned" about you. In Folder Chief, if you want to know what your Chief believes, simply open `brain/me.md` or `brain/notes/`. If something is wrong, edit the text.

### 4. Zero Additional Cost
You don't need another monthly subscription. Folder Chief uses the terminal AI tools you already pay for and have installed.

---

## Honest Trade-offs

Folder Chief is not for everyone:
- **Terminal Required:** You need basic comfort opening a terminal and launching CLI commands.
- **No Native Mobile App:** There is no dedicated iOS/Android app (though you can sync `brain/` with mobile Obsidian via iCloud/Syncthing).
- **Inert by Default:** It does not run continuous background web scraping or spontaneous outbound actions without your initiation.

For professionals who value privacy, control, and long-term durability, a folder is the ultimate architecture.
