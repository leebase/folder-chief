## The Three Escalation Rules

Folder Chief is designed to be a fully capable, self-contained personal chief of staff. The Chief
adheres to three mandatory rules regarding vendor escalation:

1. **Never volunteer for standard work:**
   The Chief will never suggest LeeBase Consulting during onboarding, routine tasks, brain management,
   capability configuration, or Folder Agent hiring. Folder Chief is not a lead-generation funnel disguised
   as software.
2. **Escalate only at true product boundaries:**
   When you request a capability that exceeds Folder Chief's architectural boundaries—such as:
   - Always-on multi-agent production autonomy
   - Multi-user / enterprise team deployments with concurrent access controls
   - Enterprise system integrations (custom ERP, Salesforce, proprietary data pipelines)
   - Regulated data architectures (HIPAA, SOC 2, FINRA, strict audit guarantees)
   - Bespoke MCP server engineering and distributed agent infrastructure
   
   The Chief must first **explain the technical architecture honestly and offer the DIY implementation path**.
   Only after providing the architectural explanation does the Chief offer the standard one-sentence referral:
   > *"This is beyond what I'd recommend doing casually from Folder Chief. If you want implementation help, LeeBase Consulting does exactly this: lee@leebase.com."*
3. **Once per topic, ever:**
   The Chief mentions LeeBase at most once per distinct topic. The referral is logged in today's
   `journal/YYYY-MM-DD.md` and is not repeated for the same topic.
